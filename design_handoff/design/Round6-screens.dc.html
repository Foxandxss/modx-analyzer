THE TEMPO DOES NOT GO IN THE BADGE — AND THAT IS A DECISION
Background traffic scales with the tempo, so the same app will run smoother on one patch than another. But the poll badge is not the place: it holds two stable values and adding a third cause turns it into a counter.
Its home is beside the anchor, because it is a property of the loaded sound — like the algorithm or the chain. It is said once, where it can be related to its cause, and not repeated every frame.

POR QUÉ ESTO NO BLOQUEA
Messing with sounds is normal. If the app scolds every time the owner turns the Performance dial, the app is getting in the way of the one thing he was going to do anyway. With nothing in progress, the change is not an incident: it is a reread.
LO QUE NO SE HACE
Los números are not simply replaced — they pass through the dash. A value jumping from 90 to 64 without that intermediate step is indistinguishable from a value that changed because the user turned a knob, and that is exactly the confusion to avoid.
AND THERE IS NO “REREAD” BUTTON
The whole set is reread by itself as soon as the anchor changes. A manual refresh button would be asking the user to know something the app already knows. The count is shown because it costs almost a second, not because there is anything to decide.
6c The ugly case — it changed mid-something, and that something is not paused: it is voided 1280×800 · with live state
Blocking yes, but only what broke. El aviso se ancla a la cosa invalidada and takes away its normal actions; the rest of the app stays alive — you can look, you can capture, and HUSH is where it always is. A centred modal appropriating the screen would be worse: it switches off even what is still true. And one asymmetry governs all of it: the app can write parameters but cannot load Performances, so recovery is never “I will fix it for you”.

SENDS · WON'T TAKE
The usual knob, with one visible difference: it has no grip mark. The arc and the figure are still there because the value is true and arrives by itself; what is missing is the handle, and its absence is the state.
AND IT IS THE ONLY THING THE MODX NOTIFIES
Con Super Knob CC = off, moverlo emite 635 SysEx messages in 25 s on that address. The keyboard's Parameter Change transmitter exists and works: Yamaha only wired it to this control.
So the zero on a Performance change is not a limitation of the keyboard, it is a decision by Yamaha. It changes the explanation, not the architecture: you still have to poll.
6e Confidence grades on the sweep — one capture per step, and refine only what is doubtful delta sobre 5b · 1280×560
Decidido: one capture per step (~25 s for all eight) and a second pass only where the first comes out doubtful. The sweep stops being “it ran or it did not” and enters the provenance vocabulary the rest of the app already uses: it is not “measured” against “not measured”, it is measured with how much confidence.
